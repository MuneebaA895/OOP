# Object-Oriented Programming (OOP) Lessons

This repository contains my lesson codes for learning **Object-Oriented Programming** in three languages: C++, Java, and Python. Each folder covers the same core OOP ideas in a different language.

## Folders

### C_plus_plus_OOP
Lessons and labs written in **C++**. Each `Lesson` folder holds the source files (`.cpp` / `.h`) for that week's topic.

### Java_OOP
Lessons and labs written in **Java**, covering OOP concepts using Java syntax and features. Contains `Lesson_10` and `Lesson_11`.

### Python_OOP
Lessons and labs written in **Python**, showing OOP in a more concise, dynamically typed style. Contains a single script, `OOP_PYTHON.py`.

## Topics Covered

- Classes and objects
- Constructors and destructors
- Encapsulation (access modifiers, getters and setters)
- Inheritance
- Polymorphism (overloading, overriding, virtual functions)
- Abstraction (abstract classes and interfaces)
- Operator overloading


## How to Run

### C++
Requires a C++ compiler such as `g++`.

```bash
cd C_plus_plus_OOP/Lesson1
g++ main.cpp -o main
./main        # on Windows: main.exe
```

### Java
Requires the JDK.

```bash
cd Java_OOP/Lesson_10
javac FileName.java
java FileName
```

### Python
Requires Python 3.

```bash
cd Python_OOP
python OOP_PYTHON.py
```
